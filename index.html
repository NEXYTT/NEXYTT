Cómo está construido

Estructura

NEXYTT/
├─ assets/            código compartido por los dos proyectos
│  ├─ css/            tokens.css (única fuente de color) + base.css
│  └─ js/             dom, format, storage, emitter, icons
├─ casino/
│  ├─ css/            shell, mesa, cartas, fichas
│  ├─ js/core/        sha256, rng, wallet, responsible, cards, context
│  ├─ js/games/       lógica pura de cada juego, sin DOM
│  └─ js/ui/          controladores de pantalla
├─ shop/
│  ├─ data/           catálogo de 26 productos y proveedores
│  ├─ js/core/        pricing, cart, catalog, orders
│  └─ js/ui/          escaparate, ficha, carrito, checkout
├─ docs/ARQUITECTURA.md   el contrato entre módulos
└─ tests/             smoke test de navegador + lógica pura

La misma regla en los dos proyectos: la lógica vive en js/core/ y no toca el DOM, así que se ejecuta igual en el navegador y bajo node --test.

  • Cero dependencias

    Ni npm install ni transpilación. Todo son módulos ES nativos, así que cualquier página se sirve tal cual y sigue funcionando dentro de diez años.

  • El dinero es entero

    Saldos, precios e importes viajan en unidades menores (céntimos). Un float nunca sostiene un saldo: el redondeo ocurre una sola vez, al mostrarlo.

  • La lógica es pura

    Los módulos de dominio reciben el almacenamiento inyectado y devuelven datos. Sin DOM dentro, se pueden probar de verdad y no solo hacer clic encima.

  • RNG sembrado

    Cada ronda del casino nace de una semilla y un nonce. Es reproducible, es auditable y por eso se puede publicar el compromiso antes de jugar.

Aviso honesto

El casino no es un casino

Se juega con créditos virtuales sin valor monetario. No hay depósitos, ni retiradas, ni premios: el saldo vive en el navegador y se recarga con un botón.

Un casino con dinero real es otra cosa por completo. En España necesita licencia de la DGOJ, verificación de identidad y edad de cada jugador, inscripción en el registro de interdicciones, prevención de blanqueo de capitales, un RNG certificado por un laboratorio externo y los datos alojados bajo supervisión del regulador. Nada de eso se resuelve con código de escaparate, y este proyecto no lo pretende.

Si el juego deja de ser un entretenimiento para ti, en España puedes llamar al 900 200 225, la línea gratuita y confidencial de FEJAR.

La tienda no cobra

El checkout es una simulación: no se conecta con ninguna pasarela, no se procesa ningún cobro y no se envía ningún paquete. Los productos, los precios y los proveedores son datos de ejemplo hechos para que los cálculos de margen tengan sentido.

Los pedidos, la cesta y la lista de deseos se guardan solo en tu navegador. No hay servidor detrás, así que tampoco hay nada que enviar a ninguna parte.
